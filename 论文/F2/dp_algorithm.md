# F2 || ∑ W_j C_j 动态规划算法设计

基于最优解的分块结构性质，参考 F2|r_j|Cmax PTAS（Hall 1998 / Kovalyov & Werner 1997）中**区间划分 + 状态压缩**的动态规划思想，设计如下算法。

---

## 问题性质（来自 note.md）

1. **同排序性质**：两台机器上工件加工顺序一致（Permutation Schedule），已有经典结论。
2. **全局 Johnson 初始序列**：将所有 n 个工件（不论权重）统一按 Johnson 规则（SPT(1)-LPT(2)）排序，得到初始序列 S = [j₁, j₂, …, jₙ]。
3. **权重分块**：扫描 Johnson 序列 S，每当遇到**之前从未出现过的权重**时，该工件（携带新权重）作为当前块的**最后一个工件**，在此处切割关闭当前块；下一个工件开启新块。即：扫描中标记当前块序号 m，遇到新权重时切割（新权重工件属于当前块末尾），共得**最多 K 个块** B₁, B₂, …, B_K。
4. **位置约束**：块 B_k 中的工件只能出现在前 k 个块对应的位置范围内。
5. **块尾约束**：第 k 块的最后一个工件权重与块内工件权重一致（由分块方式自动保证）。

## 与 F2|r_j|Cmax PTAS 的对应关系

| F2\|r_j\|Cmax PTAS | 本算法 |
| --- | --- |
| 按释放日期 r_j 划分区间 | 按 Johnson 序列中新权重出现处切割，新权重为块末尾 |
| 工件只能放入 r_j 对应的区间及之后 | 工件只能放入对应块及之前的范围 |
| 区间内按 Johnson 序排列 | 初始序列全局按 Johnson 序排列，块内保持 S 中的相对顺序 |

| 目标：最小化 Cmax | 目标：最小化 ∑ W_j C_j |

## 算法描述

### 预处理

1. **全局 Johnson 排序**：将所有 n 个工件（不论权重）统一按 Johnson 规则（SPT(1)-LPT(2)）排序，得到初始序列 S = [j₁, j₂, …, jₙ]。

2. **按新权重切割分块**：扫描 S，以 m 标记当前块序号。维护已见权重集合 `seen` 和块起始位置 `start`。遍历中遇到新权重：m 自增，当前块 B_m = S[start .. i]（包含该新权重工件作为块末尾），然后 `start = i+1` 开启下一块。最多得 K 个块 B₁, B₂, …, B_K。块 B_m 是 S 的连续子序列，同时也是该块的工件列表 B_m = [j_{m,1}, …, j_{m,|B_m|}]。

### 核心思想

每个 DP 状态隐式对应一个部分调度 π，π 由 DP 构造路径确定但不显式存储。状态仅保留 (A, B, z, l) 四个标量。

算法按 B_1 → B_2 → … → B_M 的顺序依次处理每个工件。对工件 j ∈ B_m，将其追加到当前 π 的末尾，增量更新 A、B、z。块 B_m 的最后一个工件处理完毕时，检查 W(B_m) ≤ l（权重非递增），不满足则丢弃该状态。每处理完一个工件后，仅保留 z 最小的状态进入下一轮。

### 状态定义

$$(A,\; B,\; z,\; l)$$

- A：当前部分调度在 M1 上的累计完工时间
- B：当前部分调度在 M2 上的累计完工时间
- z：当前部分调度的完成时间（makespan），z = B
- l：参考权重，即上一个已完成的块的权重 W(B_{m-1})，用于约束检查；初始值 l = +∞（使首块检查自动通过）

**说明**：每个状态 $(A, B, z, l)$ 隐式对应一个部分调度 π（由 DP 构造路径唯一确定），但 π 不显式出现在状态元组中。状态仅保留增量计算所需的 4 个标量值。初始状态：(0, 0, 0, +∞)，对应 π = ∅。

### 单步决策——追加到末尾

遍历到工件 j ∈ B_m，当前状态为 (A, B, z, l)。将 j **追加**到当前部分调度的末尾。

**增量计算**（j 排在最后，无需知晓前方排列）：

1. 更新 M1 完工时间：A' = A + a_j
2. 更新 M2 完工时间：B' = max(B, A') + b_j
3. 更新完成时间：z' = B'
4. 更新参考权重 l'：若 j 是块 B_m 的最后一个工件（i = |B_m|），则 l' = W(B_m)；否则 l' = l（保持不变）
5. **立即检查约束**（见下节）

### 追加时约束检查

在追加 j ∈ B_m 并更新状态后，检查以下条件：

1. **位置约束**：由于采用追加模式，工件依次排在末尾，块 B_m 的工件自然落在块 B_{m-1} 之后、块 B_{m+1} 之前。追加顺序遵循 B_1 → B_2 → …，位置约束自动满足。

2. **块尾约束**的递进检查：在追加 j 后，**仅当 j 是块 B_m 的最后一个工件（即 B_m 中全部工件已处理完）** 时，才检查：

   若当前是 B_m 的最后一个工件（i = |B_m|），则检查：
   $$W(B_m) \le l$$

   即当前块的权重不大于状态中保存的参考权重（上一已完成块的权重）。该条件保证权重按块非递增，与性质"权重分块按降序排列"一致。若不满足，该状态非法，直接丢弃。

**正确性**：当块 B_m 全部处理完毕后，W(B_m) 为该块末尾工件权重，l 为前一已完成块末尾工件权重。检查 W(B_m) ≤ l 确保块间权重非递增。若违反，已固定的前缀块权重无法通过后续追加改变，可安全剪枝。检查通过后 l 更新为 W(B_m)，供下一块比较。

### 保留最优

对每个状态 (A, B, z, l)，追加 j 后得到唯一候选 (A', B', z', l')。若该候选通过约束检查，则加入 Y_new；每处理完一个工件后，从 Y_new 中**仅保留 z 最小的那些**作为新状态，丢弃其余。

### 提取最优

全部 n 个工件处理完毕后，所有存活的状态均满足结构性质。取 `min{ z | (A, B, z, l) ∈ Y }` 得到最小 makespan，对应的调度即为最优调度，其总加权完工时间 Z* 可从最终排列中计算得出。

## 完整伪代码

```text
Algorithm DP_F2_WeightedSum(J, a, b, w):

    S = Johnson_Sort(J)
    seen = { w_{S[1]} }
    start = 1
    M = 0
    for i = 2 to n:
        if w_{S[i]} ∉ seen:
            M = M + 1
            B_M = S[start .. i]
            seen = seen ∪ { w_{S[i]} }
            start = i + 1
    if start ≤ n:
        M = M + 1
        B_M = S[start .. n]

    Y = { (A=0, B=0, z=0, l=+∞) }

    for m = 1 to M:
        w_m = W(B_m)
        for i = 1 to |B_m|:
            j = B_m[i]
            Y_new = ∅

            for each (A, B, z, l) ∈ Y:
                A' = A + a_j
                B' = max(B, A') + b_j
                z' = B'

                if i = |B_m|:
                    if w_m > l:
                        continue
                    l' = w_m
                else:
                    l' = l

                Y_new = Y_new ∪ { (A', B', z', l') }

            z_min = min{ z' | (A', B', z', l') ∈ Y_new }
            Y = { s ∈ Y_new | s.z = z_min }

    return min{ z | (A, B, z, l) ∈ Y }
```

---

## 算法要点

1. **逐工件追加，块内保持 S 中相对顺序**：每个工件 j 到达时追加到当前调度末尾。工件按权重首次出现顺序分块后依次遍历，块 B_m 内工件保持它们在 Johnson 序列 S 中的相对顺序。

2. **约束在追加时立即检查**：位置约束由追加顺序自动满足（按 B_1→B_2→… 依次追加）；块尾约束在块 B_m 全部处理完毕时检查 `W(B_m) ≤ l`（权重非递增），一旦违反立即丢弃。

3. **增量计算**：追加 j 到末尾时，A' = A + a_j，B' = max(B, A') + b_j，z' = B'。所有计算 O(1) 完成，无需全序模拟。

4. **Prune 保留最优**：每轮处理完一个工件后，从 Y_new 中仅保留 z 最小的状态（或并列最优的少数几个），丢弃其余以控制状态数。

5. **无单独的终止校验**：约束在每一轮递进检查完毕，全部工件处理完后所有存活状态均合法。

---

## 复杂度分析

- **状态数**：追加模式下每个父状态仅产生一个子状态，|Y| 不会自然膨胀。Prune 策略将每轮状态数控制在常数或 O(1)~O(n) 量级。

- **转移开销**：每状态转移仅 O(1)（三次算术运算与一次比较），无需全序模拟。每轮总开销 O(|Y|)。

- **总复杂度**：
  $$O\left(|Y|_{\max} \cdot n\right)$$

  其中 |Y|_max 为单轮最大状态数。此为一**增量追加式**动态规划，较原插入式 O(|Y|_max · n³) 有大幅改善。l 为标量参考权重，状态中仅 4 个数值字段，空间开销 O(1) 每状态。

- **PTAS 路径**：对权重做几何舍入使不同权重种类数 K = O((1/ε) log W_max)；块数（总块数）≤ K，最坏 O((1/ε) log W_max)。对加工时间做倍数舍入，即可在 poly(n, 1/ε) 时间内得到 (1+ε) 近似解。
