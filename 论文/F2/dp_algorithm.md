# F2 || ∑ W_j C_j 动态规划算法设计

基于最优解的分块结构性质，参考 F2|r_j|Cmax PTAS（Hall 1998 / Kovalyov & Werner 1997）中**区间划分 + 状态压缩**的动态规划思想，设计如下算法。

---

## 问题性质（来自 note.md）

1. **同排序性质**：两台机器上工件加工顺序一致（Permutation Schedule），已有经典结论。
2. **权重分块**：将工件按权重分为 K 类，W_1 > W_2 > ... > W_K。最优调度可划分为 K 个连续逻辑区间（块）。
3. **位置约束**：π(J_k) ≤ k，即第 k 类工件只能出现在前 k 个块中。
4. **块尾约束**：第 k 块的最后一个工件权重为 W_k。
5. **块内排序**：每个块内部的工件遵循 SPT(1)-LPT(2) 规则（Johnson 序）。

---

## 与 F2|r_j|Cmax PTAS 的对应关系

| F2\|r_j\|Cmax PTAS | 本算法 |
| --- | --- |
| 按释放日期 r_j 划分区间 | 按权重 W_k 划分区间（块） |
| 工件只能放入 r_j 对应的区间及之后 | 工件只能放入权重类对应的块及之前（π(J_k) ≤ k） |
| 区间内按 Johnson 序排列 | 块内按 Johnson 序排列 |
| DP 状态记录各区间的 M2 完工时间 | DP 状态记录当前调度序列的 A 与 B |
| 目标：最小化 Cmax | 目标：最小化 ∑ W_j C_j |

## 符号表

| 符号 | 含义 |
| --- | --- |
| n | 工件总数 |
| K | 权重类别数 |
| J_k | 权重为 W_k 的工件集合（k = 1,…,K） |
| W_k | J_k 的公共权重，W_1 > W_2 > … > W_K |
| n_k | \|J_k\|，第 k 类工件数 |
| a_j | 工件 j 在机器 1 上的加工时间 |
| b_j | 工件 j 在机器 2 上的加工时间 |
| w_j | 工件 j 的权重（j ∈ J_k ⇔ w_j = W_k） |
| L_k | J_k 按 Johnson 序排列后的有序列表 |
| π | 当前已构建的部分调度序列（工件的排列） |
| last[k] | 当前 π 中 J_k 类工件出现的最靠后位置（无则为 0） |
| A | 按 π 的顺序在 M1 上加工完所有工件的累计时间 |
| B | 按 π 的顺序在 M2 上加工完所有工件的完工时间 |
| z | 按 π 的顺序加工所得累计加权完工时间和 ∑ w_j C_j |
| Y | DP 状态集合（当前部分调度及其评价值） |
| Z* | 最优（最小）总加权完工时间 |

## 算法描述

### 预处理

将工件按权重分组得到 J_1,…,J_K（W_1 > … > W_K）。对每组 J_k 内部按 Johnson 规则排序，得到有序列表 L_k = [j_{k,1}, …, j_{k,n_k}]。

### 核心思想

依次遍历 L_1 → L_2 → … → L_K 中的每个工件。对每个新工件 j ∈ J_k，在当前部分调度 π 的**每个可能位置**尝试插入，计算插入后的目标函数值，仅保留 z 最小的那个插入结果。同时，在每类工件全部处理完毕时**立即检查结构性质**，将不满足约束的状态提前剔除。

### 状态定义

$$(\pi,\; A,\; B,\; z,\; last[1..K])$$

- π：当前已安排工件的排列
- A, B, z：按 π 加工的累计评价值
- last[k]：π 中 J_k 类工件的最后出现位置（若 J_k 尚未有任何工件，则 last[k] = 0）

初始状态：(∅, 0, 0, 0, [0,…,0])。

### 单步决策——插入到每个位置

遍历到工件 j ∈ J_k，当前状态为 (π, A, B, z, last)。π 的长度 N = |π|。

**候选位置**：pos ∈ {0, 1, …, N}，共 N+1 个。每个 pos 表示将 j 插入到 π[pos] 之后（pos=0 表示插入到最前面）。

对每个候选位置 pos：

1. 构造 π' = π[1..pos] \|\| j \|\| π[pos+1..N]
2. 更新 last'：
   - 对每个 m ≠ k：last'[m] = (last[m] ≤ pos ? last[m] : last[m] + 1)（插入点之后的工件右移 1 位）
   - last'[k] = pos + 1（j 的新位置）
3. 对 π' 从头模拟流水车间加工，计算 (A', B', z')
4. **立即检查约束**（见下节）

### 插入时约束检查

块尾约束等价于：对任意 m，J_m 类工件的最后出现位置必须晚于 J_1..J_{m-1} 中所有工件的最后出现位置（即权重越高的类，其最后一个工件出现得越早）。形式化地：

$$last[1] \le last[2] \le \dots \le last[K]$$

在插入 j ∈ J_k 并更新 last' 后，检查以下条件：

1. **位置约束**（性质 3）：j 所在的块不能超过 k。插入 j 后，其块归属取决于 last'[1..k] 中最大值的位置。若 last'[k] < last'[t]（其中 t < k），说明 j 被插到了某个 J_t 的最后一个工件之前，而该 J_t 末尾才是块边界 ⇒ 此时 j 处于块 t 中（t ≤ k），合法。

   等价检查：j ∈ J_k 不得被放置在任何"闭合"的、索引 < k 的块之后。计算块 k-1 的终点 = max_{t≤k-1} last'[t]。若 pos+1 ≤ 块 k-1 的终点，则 j 在块 1..k-1 中 ⇒ 合法。若 pos+1 > 块 k-1 的终点，则 j 在块 k 或之后 ⇒ 此时再检查 j 是否可能落在块 k+1 或之后（位置约束禁止）。由于 J_{k+1}..J_K 尚未安排，不会有块 k+1 的终点 ⇒ 合法。因此位置约束对每个插入位置自动满足。

2. **块尾约束**（性质 4）的递进检查：在插入 j 后，**仅当 j 是 J_k 类的最后一个工件（即 L_k 中全部工件已处理完）** 时，才检查 last' 的单调性：

   若当前是 L_k 的最后一个工件（i = n_k），则对 m = 1..k 检查：
   $$last'[1] \le last'[2] \le \dots \le last'[k]$$

   若不满足，该状态非法，直接丢弃。

**为什么可以这样检查？** 因为每类工件全部处理完毕后，其 last 值就不会再变了（后续插入只会让 last[k] 右移或不动）。一旦 last[t] > last[t+1]（对某 t），插入更多工件只会使不等号方向加剧而不会逆转。因此在不满足的瞬间立即丢弃，与最终丢弃等价——但状态数更少。

### 保留最优

对每个状态 (π, A, B, z, last)，在尝试 j 的 N+1 个插入位置后，**仅保留 z' 最小的那些**作为新状态，丢弃其余。

### 提取最优

全部 n 个工件处理完毕后，所有存活的状态均满足四个结构性质。取 `min{ z | (π, A, B, z, last) ∈ Y }` 即得 Z*。

## 完整伪代码

```text
Algorithm DP_F2_WeightedSum(J, A, B, W):

    // ===== 预处理 =====
    Group jobs by weight → J_1..J_K (W_1 > ... > W_K)
    For k = 1 to K:
        L_k = Merge_By_Johnson(J_k)

    // ===== 初始化 =====
    Y = { (π=∅, A=0, B=0, z=0, last=[0,...,0]) }

    // ===== 依次遍历每个 L_k 的每个工件 =====
    for k = 1 to K:
        for i = 1 to n_k:
            j = L_k[i]              // 当前工件
            Y_new = ∅

            for each (π, A, B, z, last) ∈ Y:
                N = |π|
                best_z = +∞
                best_states = ∅

                // 尝试插入到每个候选位置
                for pos = 0 to N:
                    // 构造 π'
                    π' = π[1..pos] || j || π[pos+1..N]

                    // 更新 last' 数组
                    last' = copy of last
                    for m = 1 to K:
                        if last[m] > pos:
                            last'[m] = last[m] + 1      // 插入点之后右移
                    last'[k] = pos + 1                   // j 的新位置

                    // 对 π' 模拟流水车间加工
                    A_cur = 0, B_cur = 0, z_cur = 0
                    for each job x in π' (按序):
                        A_cur = A_cur + a_x
                        B_cur = max(B_cur, A_cur) + b_x
                        z_cur = z_cur + w_x · B_cur

                    // 立即检查约束（递进）
                    valid = true
                    if i == n_k:                          // J_k 全部处理完毕
                        for t = 1 to k-1:
                            if last'[t] > last'[t+1]:    // 单调性检查
                                valid = false; break
                    if not valid:
                        continue                          // 丢弃此插入结果

                    // 保留最优
                    if z_cur < best_z:
                        best_z = z_cur
                        best_states = { (π', A_cur, B_cur, z_cur, last') }
                    else if z_cur == best_z:
                        best_states = best_states ∪ { (π', A_cur, B_cur, z_cur, last') }

                // 将最优插入结果加入新状态集合
                for each s ∈ best_states:
                    Insert s into Y_new

            Y ← Y_new

    // ===== 提取最优 =====
    return min{ z | (π, A, B, z, last) ∈ Y }
```

## 算法要点

1. **逐工件插入，逐位置尝试**：每个工件 j 到达时，尝试将其插入到部分调度 π 的每个位置（0 到 N），共 N+1 种可能。不区分"块"的边界——调度就是一个全局排列。

2. **约束在插入时立即检查**：位置约束由自然插入逻辑自动满足（j ∈ J_k 可被插入到任意位置）；块尾约束在 J_k 类全部处理完毕时进行一次单调性检查 `last[1] ≤ last[2] ≤ … ≤ last[k]`，一旦违反立即丢弃。

3. **全序模拟求精确值**：每次插入后对 π' 从头至尾模拟流水车间，精确计算 (A, B, z)。代价 O(|π|) 但避免了增量近似误差。

4. **每轮仅保留最优**：每个旧状态在加入一个工件后产生 N+1 个候选；算法仅保留 z 最小的那一个（或并列最优的少数几个）。

5. **无单独的终止校验**：因为约束已在每一轮递进检查完毕，全部工件处理完后无需再过滤——所有存活状态都是合法的。

---

## 复杂度分析

- **状态数**：在最坏情况下（所有插入位置 z' 均相等），|Y| 每轮可能翻 N+1 倍 ⇒ O(n!)。实践中"保留最优"策略使每轮状态增长极有限（通常在 O(1)~O(n) 量级）。

- **转移开销**：每轮每个状态尝试 O(N) 个位置，每次全序模拟 O(N) 步，合计每状态 O(N²) ≈ O(n²)。N 随遍历线性增长至 n。

- **总复杂度**：
  $$O\left(|Y|_{\max} \cdot n^3\right)$$

  其中 |Y|_max 为单轮最大状态数。此为一**迭代构造式**动态规划。

- **PTAS 路径**：对权重做几何舍入使 K = O((1/ε) log W_max)，对加工时间做倍数舍入，即可在 poly(n, 1/ε) 时间内得到 (1+ε) 近似解。
