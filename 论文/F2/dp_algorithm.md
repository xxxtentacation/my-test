# $F2 \parallel w_j C_{\max}$ 动态规划算法设计

基于最优解的分块结构性质，参考 F2|r_j|Cmax PTAS（Hall 1998 / Kovalyov & Werner 1997）中**区间划分 + 状态压缩**的动态规划思想，设计如下算法。

---

## 问题性质（来自 note.md）

1. **同排序性质**：两台机器上工件加工顺序一致（Permutation Schedule），已有经典结论。
2. **全局 Johnson 初始序列**：将所有 n 个工件（不论权重）统一按 Johnson 规则（SPT(1)-LPT(2)）排序，得到初始序列 S = [j₁, j₂, …, jₙ]。
3. **权重分块**：扫描 Johnson 序列 S，每当遇到**之前从未出现过的权重**时，该工件（携带新权重）作为当前块的**最后一个工件**，在此处切割关闭当前块；下一个工件开启新块。即：扫描中标记当前块序号 k，遇到新权重时切割（新权重工件属于当前块末尾），共得**最多 K 个块** B₁, B₂, …, \mathcal{G}_K。
4. **位置约束**：块 \mathcal{G}_k 中的工件只能出现在前 k 个块对应的位置范围内。
5. **块尾约束**：第 k 块的最后一个工件权重与块内工件权重一致（由分块方式自动保证）。

| 按释放日期 r_j 划分区间 | 按 Johnson 序列中新权重出现处切割，新权重为块末尾 |

## 算法描述

### 预处理

1. **全局 Johnson 排序**：将所有 n 个工件（不论权重）统一按 Johnson 规则（SPT(1)-LPT(2)）排序（若存在tie，则权重大的优先），得到初始序列 S = [j₁, j₂, …, jₙ]。

2. **按新权重切割分块**：扫描 S，以 k 标记当前块序号。维护已见权重集合 `seen` 和块起始位置 `start`。遍历中遇到新权重：k 自增，当前块 \mathcal{G}_k = S[start .. i]（包含该新权重工件作为块末尾），然后 `start = i+1` 开启下一块。最多得 K 个块 B₁, B₂, …, \mathcal{G}_K。块 \mathcal{G}_k 是 S 的连续子序列，同时也是该块的工件列表 \mathcal{G}_k = [j_{k,1}, …, j_{k,|\mathcal{G}_k|}]。

### 核心思想

每个 DP 状态隐式对应一个部分调度 π，π 由 DP 构造路径确定但不显式存储。状态仅保留 $(A, B, C, L)$ 四个标量。

算法按 $\mathcal{G}_1 → \mathcal{G}_2 → … → \mathcal{G}_K$ 的顺序依次处理每个工件。对工件 $j ∈ \mathcal{G}_k$，将其追加到当前 π 的末尾，增量更新 A、B、C，并更新 $L = \max(L,\; w_j \cdot C')$ 对应的权重。块 $\mathcal{G}_k$ 的最后一个工件处理完毕时，检查 $W(\mathcal{G}_k) \le L$（权重非递增），不满足则丢弃该状态。每处理完一个工件后，由于 $L$ 直接追踪当前部分调度中最大 $w_j C_j$ 对应的权重，仅需保留关于 $(C, L)$ 的 Pareto 最优状态。最终目标值 $C^* = \max_j w_j C_j$ 从终态 $L$ 直接读取。

### 状态定义

$$(A,\; B,\; C,\; L)$$

- A：当前部分调度在 M1 上的累计完工时间
- B：当前部分调度在 M2 上的累计完工时间
- C：当前部分调度的完成时间（makespan），C = B
- L：当前部分调度中取得最大 $w_j C_j$ 的那个工件的权重 $w_{j^*}$；初始值 L = 0（无工件时最大加权完成时间为 0）

**说明**：每个状态 $(A, B, C, L)$ 隐式对应一个部分调度 π（由 DP 构造路径唯一确定），但 π 不显式出现在状态元组中。状态仅保留增量计算所需的 4 个标量值。初始状态：$(0, 0, 0, 0)$，对应 π = ∅。L 直接追踪到当前为止使 $w_j C_j$ 最大化的工件权重——最终算法结束时，$L$ 即为最优目标值 $\max_j w_j C_j$ 中的最大权重部分。

### 单步决策——追加到末尾

遍历到工件 j ∈ \mathcal{G}_k，当前状态为 (A, B, C, L)。将 j **追加**到当前部分调度的末尾。

**增量计算**（j 排在最后，无需知晓前方排列）：

1. 更新 M1 完工时间：A' = A + a_j
2. 更新 M2 完工时间：B' = max(B, A') + b_j
3. 更新完成时间：C' = B'
4. 更新最大权重 L'：计算 $w_j \cdot C'$，若 $w_j \cdot C' > L \cdot C$，则 $L' = w_j$；否则 $L' = L$（保持不变）
5. **立即检查约束**（见下节）

### 追加时约束检查

在追加 j ∈ \mathcal{G}_k 并更新状态后，检查以下条件：

1. **位置约束**：由于采用追加模式，工件依次排在末尾，块 \mathcal{G}_k 的工件自然落在块 \mathcal{G}_{k-1} 之后、块 B_{k+1} 之前。追加顺序遵循 \mathcal{G}_1 → \mathcal{G}_2 → …，位置约束自动满足。

2. **块尾约束**的递进检查：在追加 j 后，**仅当 j 是块 \mathcal{G}_k 的最后一个工件（即 \mathcal{G}_k 中全部工件已处理完）** 时，才检查：

   若当前是 \mathcal{G}_k 的最后一个工件（i = |\mathcal{G}_k|），则检查：
   $$W(\mathcal{G}_k) \le L$$

   即当前块的权重不大于状态中已记录的最大 $w_j C_j$ 对应的权重。该条件保证权重按块非递增，与性质"权重分块按降序排列"一致。若不满足，该状态非法，直接丢弃。

**正确性**：当块 \mathcal{G}_k 全部处理完毕后，W(\mathcal{G}_k) 为该块末尾工件权重，L 为到目前位置取得最大 $w_j C_j$ 的工件的权重。检查 W(\mathcal{G}_k) ≤ L 确保块间权重非递增，这对 $w_j C_{\max}$ 目标的最优性是必要的——权重更大的块排在后面会放大 makespan 的加权值。若违反，已固定的前缀块权重无法通过后续追加改变，可安全剪枝。检查通过后，若当前工件的 $w_j \cdot C'$ 刷新了最大加权完成时间，L 已在增量计算第 4 步中更新为 $w_j$。

### 保留最优

对每个状态 (A, B, C, L)，追加 j 后得到唯一候选 (A', B', C', L')。若该候选通过约束检查，则加入 Y_new；每处理完一个工件后，从 Y_new 中移除被支配状态：若存在两个状态 s, s' 满足 s.C ≤ s'.C 且 s.L ≤ s'.L，且至少一个不等式严格成立，则 s' 被 s 支配，可丢弃。仅保留关于 (C, L) 的 Pareto 最优状态进入下一轮。

### 提取最优

全部 n 个工件处理完毕后，所有存活状态均满足结构性质。最优目标值为 $C^* = \min\{\, L \mid (A, B, C, L) \in \mathcal{Y} \,\}$。由于 L 已在增量计算中持续追踪当前部分调度的最大 $w_j C_j$，终态中最小 L 即为全局最优目标值 $\max_j w_j C_j$。

## 完整伪代码

```text
Algorithm DP_F2_wCmax(J, a, b, w):

    S = Johnson_Sort(J)
    start = 1
    K = 0
    for i = 2 to n:
        if w_{S[i]} appears for the first time:
            K = K + 1
            \mathcal{G}_K = S[start .. i]
            start = i + 1
    if start ≤ n:
        K = K + 1
        \mathcal{G}_K = S[start .. n]

    Y = { (A=0, B=0, C=0, L=0) }

    for k = 1 to K:
        w_k = W(\mathcal{G}_k)
        for i = 1 to |\mathcal{G}_k|:
            j = \mathcal{G}_k[i]
            Y_new = ∅

            for each (A, B, C, L) ∈ Y:
                A' = A + a_j
                B' = max(B, A') + b_j
                C' = B'
                if w_j * C' > L * C:
                    L' = w_j
                else:
                    L' = L

                if i = |\mathcal{G}_k|:
                    if w_k > L':
                        continue
                    // L' 已在上面更新（若 j 刷新了最大加权完成时间）

                Y_new = Y_new ∪ { (A', B', C', L') }

            // Pareto 剪枝：保留关于 (C, L) 的最优状态
            Remove from Y_new any state s dominated by s' (s'.C ≤ s.C and s'.L ≤ s.L, strict at least once)
            Y = Y_new

    C* = min{ L | (A, B, C, L) ∈ Y }
```

---

## 算法要点

1. **逐工件追加，块内保持 S 中相对顺序**：每个工件 j 到达时追加到当前调度末尾。工件按权重首次出现顺序分块后依次遍历，块 \mathcal{G}_k 内工件保持它们在 Johnson 序列 S 中的相对顺序。

2. **约束在追加时立即检查**：位置约束由追加顺序自动满足（按 \mathcal{G}_1→\mathcal{G}_2→… 依次追加）；块尾约束在块 \mathcal{G}_k 全部处理完毕时检查 `W(\mathcal{G}_k) ≤ L`（权重非递增），一旦违反立即丢弃。

3. **增量计算**：追加 j 到末尾时，A' = A + a_j，B' = max(B, A') + b_j，C' = B'，若 $w_j \cdot C' > L \cdot C$ 则更新 $L' = w_j$。所有计算 O(1) 完成，无需全序模拟。

4. **Prune 保留最优**：每轮处理完一个工件后，从 Y_new 中移除关于 (C, L) 被支配的状态（C 和 L 均不优），仅保留 Pareto 前沿上的状态进入下一轮，以控制状态数。

5. **无单独的终止校验**：约束在每一轮递进检查完毕，全部工件处理完后所有存活状态均合法。

## 复杂度分析

由于算法按固定序列（块划分 + 块内 Johnson 序）依次处理工件，在任一处理阶段，已调度工件集合唯一确定。因此，累计 M1 时间 $A = \sum a_j$ 在 $\mathcal{Y}$ 中取唯一值，$B$ 和 $C = B$ 同样唯一。L 追踪当前部分调度中最大 $w_j C_j$ 对应的权重，在同一块内可能随工件追加而递增。经 Pareto 剪枝后，非最优的 $(C, L)$ 对被丢弃；由于 $C$ 在每一阶段唯一，**恰好一个状态存活**，$|\mathcal{Y}| = 1$ 始终成立。

- **转移开销**：每状态转移 $O(1)$（三次算术运算 + 一次加权比较 + 至多一次约束检查），无需全序模拟。每轮总开销 $O(1)$。

- **总复杂度**：
  $$O(n \log n)$$
  
  其中 $O(n \log n)$ 来自初始 Johnson 排序，DP 迭代 $n$ 步、每步 $O(1)$，总计 $O(n)$；分块扫描 $O(n)$。空间开销 $O(1)$。

- **PTAS 路径**：加工时间几何舍入为 $\delta = \varepsilon \cdot P_{\max} / n$ 的倍数（$P_{\max} = \max\{\sum a_j, \sum b_j\}$）。舍入后多个工件可能共享相同 $(a_j, b_j)$ 而可互换，$A$ 在离散网格 $\{0, \delta, 2\delta, \dots, P_{\max}\}$ 上至多取 $O(n/\varepsilon)$ 个不同值，$\mathcal{B}$ 同理。共存状态数受不同 $(A, \mathcal{B})$ 对数量约束，$|\mathcal{Y}| \le O(n/\varepsilon)$。结合权重舍入（$K = O((1/\varepsilon) \log W_{\max})$），DP 总时间 $O(n^2 / \varepsilon)$，在 $n$ 与 $1/\varepsilon$ 的多项式时间内。
